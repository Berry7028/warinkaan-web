仕組み

この画面は Render 上のサーバーとブラウザを WebSocket でつなぎ、Java の割り勘アプリをそのまま操作しています。

Render

フロントエンドと Node.js サーバーを同じサービスとして Render に配置しています。ページを開くと、そのサーバーからこの画面が配信されます。

WebSocket

ブラウザの xterm.js が同一ホストへ WebSocket 接続します。接続のたびにサーバーが Java プロセスを疑似端末として起動し、キーボード入力と画面出力を双方向に転送します。接続を切るとプロセスも止まります。

流れ

  1. ブラウザが Render 上のページを開く
  2. WebSocket でサーバーへ接続する
  3. わりんかーん（Java）が起動する
  4. 入出力がリアルタイムで流れる
